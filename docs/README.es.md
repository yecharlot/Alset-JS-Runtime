# Alset-JS-Runtime (ES)

Runtime de interfaz **por pulsos**: estado granular (`alsetState`), composición `Column`/`Row`/`Text`, `AlsetInspector` monta en `#app`.

- Especificaciones AIP en `docs/AIP-*.md`
- UX: `docs/UX-Patterns.md`
- Ejemplos: `examples/`

**Contrato de montaje:** el DOM debe contener `<div id="app">` (también se acepta `#root` en versiones parcheadas).
