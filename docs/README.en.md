# Alset-JS-Runtime (EN)

**Pulse-driven** UI runtime: granular state (`alsetState`), `Column`/`Row`/`Text` composition. `AlsetInspector` mounts on `#app`.

- AIP specs: `docs/AIP-*.md`
- UX: `docs/UX-Patterns.md`
- Examples: `examples/`

**Mount contract:** DOM must include `<div id="app">` (`#root` accepted in patched builds).
